# gatetable

Gate CSV/TSV table tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/gatetable/

## Install / run

```bash
git clone https://github.com/theworker02/gatetable.git
cd gatetable
node src/cli.js
node --test
```
